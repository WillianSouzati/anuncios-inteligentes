# Anúncios Inteligentes

Crie uma aplicação web chamada IA para Anúncios Inteligentes, totalmente em português do Brasil, com aparência profissional de um produto SaaS moderno. O objetivo é ajudar vendedores a criarem anúncios melhores para marketplaces usando inteligência artificial.

DESIGN: interface moderna, minimalista, profissional, fundo claro, tons de azul e roxo discretos, boa hierarquia visual, responsiva para desktop e celular. Não quero uma landing page genérica, quero uma aplicação funcional.

TELA PRINCIPAL:

1. Cabeçalho com logotipo textual IA para Anúncios Inteligentes e menu Início, Criar anúncio e Sobre.

2. Título: Transforme as informações do seu produto em um anúncio completo.

3. Subtítulo explicando a ferramenta.

4. Formulário com campos: nome do produto (obrigatório), categoria, marca, modelo, estado de conservação, preço em reais, características e detalhes adicionais.

5. Botão Gerar meu anúncio.

6. Validar os campos obrigatórios antes do envio.

RESULTADO:

Criar uma área organizada para mostrar título sugerido, descrição, características e sugestões de melhoria. Incluir botões individuais para copiar os textos e um botão para gerar novamente.

COMPORTAMENTO:

Nesta primeira versão, criar a interface e o fluxo de navegação, com uma simulação de demonstração claramente identificada como dados fictícios. Não fingir que existe integração com IA. Preparar a estrutura para futura integração com a API Gemini por meio de backend seguro.

REQUISITOS TÉCNICOS:

Utilizar React e TypeScript. Organizar os componentes e o código. Não incluir chaves de API, senhas ou credenciais no frontend. Não implementar autenticação ou banco de dados nesta primeira versão. Não inventar funcionalidades que não foram solicitadas.

Crie uma aplicação visualmente consistente, com boa experiência do usuário, mensagens de validação, estados de carregamento e tratamento de erros. Todo o conteúdo da interface deve estar em português brasileiro.
